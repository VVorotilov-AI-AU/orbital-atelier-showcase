Harness components

A model produces the next response or decision. The harness supplies the task, available actions, continuity and acceptance checks.

These components can be simple for one task or grow into a durable operating system.

Optional explainer / Harness basics

What is a harness?

The operating layer around a model that turns reasoning into controlled action.

It assembles instructions and relevant context, runs the model-tool loop, maintains task state, and checks outcomes.

→

Triggers

Verification

Evidence that the result meets the task

A prompt is one input. The harness runs the surrounding process.
