# Orbital Atelier

A six-scene interactive field guide to reliable AI assistance and agent harnesses. It follows one
idea from capability to dependable assistance, through models, instructions, tools, memory and
checked outcomes.

[Open the interactive presentation](https://vvorotilov-ai-au.github.io/orbital-atelier-showcase/)

Scroll or use the arrow keys to move through the six scenes. Route opens the chapter map, Read
switches to the document view, and P pauses ambient motion. Optional explainers open in a dialog.
